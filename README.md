A visual novel game created by 5 Swinburne University of Technology students for the unit GAM30006 - Experimental Game Design over a period of 2 weeks. The prompt for this game was "*It was personal*". 

The story follows a man who's sandwich was stolen at work and his revenge on the one who wronged him. There are 2 sections where the player can make a choice which will affect which of the two endings will be shown.

## Getting Started
### Requirements
- A modern web browser
- [Twine](https://twinery.org/) (For editing the project)


### Installation
#### Github Pages
The game is available to play online at https://rhyslan.github.io/Sandwichpunk-2056/

#### Run Locally
1. Download the code from the [latest release](https://github.com/Rhyslan/Sandwichpunk-2056/releases/latest)
2. Open ``Sandwichpunk 2056.html`` in a web browser

#### Twine Project
1. Clone the repository
2. Open the Twine [website editor](https://twinery.org/2/#/) or download and setup the Twine [desktop editor](https://github.com/klembot/twinejs/releases)
3. Open ``Sandwichpunk 2056.html`` in the Twine editor

## Usage
The game is a basic visual novel style game. Dialogue can be progressed by clicking inside the dialogue box at the bottom of the screen (clicking the text itself will not work). The flashing dot in the bottom right of the dialogue box indicates when the current line has finished printing and the dialogue can be progressed. 

When a line of dialogue is underlined and bolded (<u>**like this**</u>), the current section has ended and the line of text can be clicked to continue. Sometimes there will be multiple of these lines, which means that the option selected with affect the direction of the story.

In the top left corner of the screen is a menu button which can be clicked to expand the game menu. This menu has the following buttons (in order):
- ``Restart``: Restarts the game from the beginning
- ``Fullscreen``: Toggles if the game is in fullscreen or not
- ``Undo``: Returns to the previous section (not dialogue line)
- ``Redo``: Returns to the previously undone section (not dialogue line)
